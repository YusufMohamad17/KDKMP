Konfigurasi Google Apps Script API

Aplikasi ini berjalan sebagai aplikasi web statis modern. Agar dapat membaca dan menulis data ke Google Spreadsheet, Anda perlu menghubungkannya dengan Web App URL Google Apps Script Anda.

Pastikan Anda telah mendeploy Apps Script dengan konfigurasi Execute as: Me dan Who has access: Anyone.

Panduan Singkat Mendapatkan URL:

  1. Buka spreadsheet Anda, masuk ke **Ekstensi → Apps Script**.
  2. Salin kode dari file `Code.gs` baru di repositori ini ke editor script Anda.
  3. Klik tombol **Deploy → New Deployment** di bagian kanan atas.
  4. Pilih jenis deployment: **Web App**.
  5. Ubah akses (Who has access) ke **Anyone** dan klik **Deploy**.
  6. Salin **Web App URL** yang dihasilkan dan tempelkan pada kolom di atas.
